
Простая утилита для очистки временных файлов Windows (кэш браузеров, системные TEMP, Prefetch). Запускайте от имени администратора для полного доступа.

⚠️ Важно про антивирусы

Файл собран с помощью PyInstaller — это стандартный инструмент для упаковки Python-программ в .exe. Из-за особенностей упаковки некоторые антивирусы могут ложно определить его как угрозу (это распространённая проблема для всех сборок PyInstaller).
