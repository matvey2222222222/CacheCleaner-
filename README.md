# CacheCleaner-
Простая утилита для очистки временных файлов Windows (кэш браузеров, системные TEMP, Prefetch). Запускайте от имени администратора для полного доступа, ВАЖНО: ПРИЛОЖЕНИЕ СОБРАНО С ПОМОЩЬЮ Pyinstaller, И ПОЭТОМУ АНТИВИРУСЫ МОГУТ ЕГО БЛОКИРОВАТЬ, ПРИЛОЖЕНИЕ НЕ СОДЕРЖИТ ВРЕДОНОСНОГО ПО!
